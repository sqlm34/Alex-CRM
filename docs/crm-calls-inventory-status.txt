MANUAL PHONE BLOCKING
Owner-authenticated manager: search, add, optional reason, Block/Unblock confirmation
and history. Direct controls in telephone call details. E.164 unique phone records.
Atomic status/audit and request-ID replay protection, including concurrent retries.
Signed Retell inbound webhook checks the destination and exact active block before
returning call_inbound.reject=true. Allowed/anonymous callers retain existing routing.
No automatic caller classification or automatic blocking.

CUSTOMERS
Clients are derived from jobs and drafts in this existing CRM; there is no separate
Customers table. Existing atomic AI booking creates the job and call.job_id association.
Calls now prefer booked-job names. Open Job/Open Customer fetches the full linked
record even before job polling catches up; Back returns to AI Receptionist.
Generated first/last name columns retain the supplied full name, with no invented surname.
Conservative identity includes normalized name/contact/address to avoid family merges.

RECEPTIONIST UI
Fixed title/tabs/date controls, independent history scroll, descending dates/times,
Today placeholder/reset, date filter, names above numbers, Unknown Caller fallback.
Visible-page polling updates calls without reinitializing Settings.
Existing recording, deletion, callbacks and map functions remain in place.

INVENTORY
Parts Inventory owner navigation, summaries, search, brand/supplier/stock/date filters,
sorting, product photos, metadata/models/location/notes, average unit cost, batches
and movement history. Part number + brand is normalized and unique.
Initial part/purchase creation is atomic. Separate FIFO batches preserve every purchase.
Integer cents and an already-included switch prevent adding tax/shipping twice.
Manual purchases work without an AI key.

INVOICE REVIEW / PHOTOS
Existing Responses recognition gains invoice number, brand and unit price in inventory
mode only; ordinary receipt recognition keeps its existing schema.
Camera/gallery/screenshots use the existing Android photo bridge when available.
Images are read before picker reset, oriented/compressed and saved in existing R2.
MIME/signature and 10 MB limit enforced. Authenticated image responses are private.
Product photos and document images remain separate; missing product photos use a placeholder.
Scans produce review only. Owner corrects quantities, part numbers, prices and dates,
matches existing parts, removes lines, verifies USD and explicitly confirms import.
Exact-image duplicates reuse recognition. Semantic duplicate checks use supplier,
invoice/date, or line fingerprint without invoice number. A suspected duplicate shows
previous purchase lines and requires a separate-new-purchase confirmation.
Existing daily scan quota is reused. No real paid AI requests made during this work.

JOBS / COSTS
Add from Inventory previews FIFO cost. Only explicit installation confirmation consumes
stock; neither selection nor customer payment does so.
One transaction creates usage/movements, decrements batches and creates a confirmed
parts_receipt; existing statistics triggers update expenses/net totals.
Return restores original batch quantity/cost and voids that expense.
Existing calculator adjusts job expense without modifying purchase cost or stock.
Inventory expenses cannot independently be voided through ordinary receipt actions.
Also corrected a misplaced receipt-restore handler found by regression tests.
